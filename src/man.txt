NAME
    info-gen — generate fake or fake-like data for testing.

SYNOPSIS
    main.py [TYPE [COUNT]] [OPTIONS]
    main.py -f FILE [COUNT] [OPTIONS]

INVOCATION
    Run via `make start ARGS="..."` or `uv run src/main.py ...`.
    Running directly will cause log file issues.
    All arguments documented below are forwarded to main.py. See
    `make-man.txt` for the full set of make targets.

DESCRIPTION
    Generates one or more values of a chosen TYPE, or — with -f —
    processes a template file containing interpolation tokens and
    substitutes a generated value for each one. See DATA REALISM
    below for which outputs are guaranteed fake and which may match
    a real entity.

POSITIONAL ARGUMENTS
    type    ssn | phone | address | typos | color | name | number | identifier
            (default: ssn)
    count   positive integer (default: 1)

GLOBAL OPTIONS
    -h, --help                  show argparse help and exit
    -u, --usage                 show the usage line and exit
    -m, --manual                show this manual and exit
    -s,  --seed N               deterministic seed for all RNGs
    -sb, --seed-byte-size N     entropy bytes when no seed is given
                                (default: 16)
    -f,  --file PATH            template-file mode (see FILE MODE)
    -cdc, --clean-dirty-colors  rewrite assets/colors.json from
                                assets/colors-dirty.json, then exit

GENERATOR TYPES

    ssn        -c START MID END
               Each component is digits (fixed) or a non-digit (e.g.
               'x') for random; 'none'/'null' selects the default for
               that slot. Default chooses a reserved fake range
               (start ∈ {000, 666, 900–999}).

    phone      -c AREA CENTRAL LINE
               Same digit/non-digit convention as ssn. Dash-joined
               input is also accepted (e.g. `-c 555-555-0100`).
               Defaults use the reserved fake range
               (central=555, line 100–199).

    number     --min FLOAT, --max FLOAT, --precision N
               Integer when precision=0 (default), float otherwise.
               --min/--max default to 0/100.

    address    -bn NUM, -ste STREET, -ci CITY, -st STATE, -z ZIP
               --no-state-abbr   keep full state names
               --no-existing-city generate a fake city name
               Real US cities/states/zips are used, but fake streets and
               building numbers are generated. Provided fields are
               cross-resolved (ZIP ↔ city/state) where possible.
               Specifying a fake city is acceptable, but fake states
               will be rejected.

    color      --min-r N / --max-r N / --exact-r N  (also -g, -b),
               each 0–255. --exact-* overrides --min-*/--max-*.
               Output: nearest real color name + RGB/Hex/HSL/CMYK.

    name       --name-type one of: company | person | file_name |
                                   website | job | music_genre |
                                   music_instrument | vehicle
                                   (default: person)
        person             -fn FIRST, -ln LAST,
                           -ge {male|female|nb},
                           -fln "First Last"
                           (-fln overrides -fn/-ln)
        file_name          -fc {audio|image|office|text|video},
                           -ft EXT  (-ft overrides -fc)
        website            -sd N    subdomain count (default 1)
        job                -ge {male|female|nb}
        music_genre        -pmg PARENT_GENRE (case-insensitive;
                           see --help for valid values)
        music_instrument   -mic CATEGORY     (case-insensitive;
                           see --help for valid values)
        vehicle, company   no extra arguments

    identifier --identifier-type {email | username} (default: email)
        email     -un USERNAME, -dm DOMAIN,
                  -dt {personal|business}
                  Missing parts are generated. When a username is
                  generated, -fn/-ln/-fln/-ge/--min/--max feed it.
        username  -fn, -ln, -fln, -ge, --min N, --max N
                  --min/--max bound the optional trailing number
                  (defaults 0/100).

    typos      -t TEXT         source text; only keyboard chars +
                               space allowed
                               (default: "Example text for typo
                               generation.")
               -ts T1 T2 ...   typo categories (see TYPO TYPES;
                               default: all)
               -tw W1 W2 ...   non-negative integer weights, paired
                               1:1 with -ts. Missing weights default
                               to 1.
               -tr RATE        per-word probability 0.0–1.0
                               (default 0.1)
               -tpw N          max typos per word (default 1)

TYPO TYPES (values for -ts)
    let-ins, let-sub, digit-ins, digit-sub, char-ins, char-sub,
    kb-ins, kb-sub, kb-ins-as, kb-sub-as,
    trans, del, case, word-dup, dbl-miss, dbl-ins,
    filler-ins, homophone

FILE MODE  (-f PATH)
    The file is read and every token of the form
        {{id: TYPE [COUNT] [OPTIONS]}}
    is parsed as a full main.py argv line, generated, and
    substituted in place.

    Back-references
        {{id}}            reuses the value generated for the first
                          {{id: ...}} occurrence. Repeating an id
                          with conflicting args is an error.

    Result-references
        $(other_id)       inside an args template, substitute the
                          resolved value of another token. The token
                          for other_id must appear somewhere in the
                          file; dependencies are resolved by
                          topological sort, and cycles are rejected.

    The outer COUNT positional applies to the whole template:
    `-f tmpl.txt 5` regenerates the entire template five times. Each
    iteration derives a per-token seed so a given id varies across
    iterations deterministically. For `color` tokens, only the color
    name (the part before the first dash) is substituted into the
    template.

    When a template is processed, the final generation is used for
    substitution.

DATA REALISM
    Guaranteed fake (never match a real entity by construction):
        ssn  (default components)
        phone (default components)
        address (streets are fake; cities/states/ZIPs are real if you don't override them)
        number, typos
        name=company, name=person, name=file_name, name=website
        identifier  (username and email local-part are synthesized)

    May correspond to real data:
        color                 nearest real color name (warns at start)
        name=job              real Faker job titles
        name=music_genre      real faker_music genres
        name=music_instrument real faker_music instruments
        name=vehicle          real make/model/year
        identifier email      domain may be a real personal or
                              business domain
        ssn / phone (overridden) user-supplied components can break
                              the reserved-range guarantee

EXAMPLES
    make start ARGS="ssn 3"
    make start ARGS="phone 1 -c 555 555 0100"
    make start ARGS="name 1 --name-type vehicle"
    make start ARGS="-f template.txt 5 -s 42"

    template.txt:
        {{id: number 1 -mn 10000 -mx 99999}},
        {{n: name 1}},
        {{e: identifier 1 -idt email -dt personal -fln "$(n)"}}
